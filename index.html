계산 방법과 가정

집속 허리 (Self의 가우시안 빔 렌즈 공식, 얇은 렌즈). 입사 허리가 렌즈 앞 din에 있을 때:

w_out = w_in·f / √((d_in−f)² + z_R,in²)
d_out = f + (d_in−f)·f² / ((d_in−f)² + z_R,in²)

레일리 길이와 근사식. 근사식과의 차이는 상세 정보에 표시합니다.

z_R,in = π·w_in² / (M²λ)
z_R = π·w_out² / (M²λ)
w_out ≈ M²fλ / (π·w_in)

결정 안. 레일리 길이가 n배 늘어나고, 길이 L인 결정은 공기 L/n과 같아서 허리가 Δz만큼 뒤로 밀립니다. 그래서 허리를 결정 중심에 두려면 앞면을 zfront에 놓습니다.

z_R(KTP) = n·z_R, b = 2·z_R(KTP), ξ = L/b
z_front = d_out − L/(2n), Δz = (L/2)(1 − 1/n)
w_face = w_out·√(1+ξ²)

개구 투과율. 결정 두께 t, 폭 W 방향의 가우시안 클리핑으로 계산해 99.5% 미만이면 경고합니다.

T = erf(√2·(t/2)/w_face) · erf(√2·(W/2)/w_face)

ξ 고르기. ξ ≈ 2.84는 Boyd–Kleinman 최적(SHG, SPDC 쌍 생성률 최대)이고, ξ ≲ 1은 단일모드 수집 효율과 스펙트럼 순도에 유리하다고 알려져 있습니다. 추천 렌즈는 개구와 간격 조건을 만족하는 렌즈 중 |ln(ξ/ξ_target)|가 가장 작은 것입니다. 근사식 오차가 1%를 넘으면 표시합니다.

굴절률 자동값. KTP ny Sellmeier 식(Kato & Takaoka, Appl. Opt. 41, 5040, 2002; 유효 범위 0.43–3.54 μm)입니다. 405 nm는 범위 밖 외삽이므로 결정 데이터시트 값이 있으면 직접 입력하세요.

n_y² = 3.45018 + 0.04341/(λ² − 0.04597) + 16.98825/(λ² − 39.43799)

한계. 거리는 얇은 렌즈의 주평면 기준입니다. 평볼록 렌즈는 주평면이 곡면 쪽 꼭짓점 근처에 있으니 마운트 위치를 보정하세요. 결정 면의 반사, 열 렌즈, 비대칭 빔은 고려하지 않았습니다.
